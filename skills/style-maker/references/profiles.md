# Profile 选择表

| Profile | 适用语料 | 重点蒸馏内容 | 特有输出 |
|---|---|---|---|
| `policy` | 政策、公文、工作部署、总结报告、调研、新闻通讯 | 政策对象、问题、任务、机制、保障、术语、公文语气、标题层级 | 内容/风格/标题/术语 references |
| `narrative` | 公众号长文、养生、生活方式、个人经验、非虚构、文化观察 | 场景、故事素材、情绪、节奏、钩子、留白、叙述视角 | 在基础 references 外增加 `narrative_style.md` 与原文证据 |

选择原则：按文章的主要写作任务选择，不按单个关键词选择。养生知识的政策解读使用 `policy`；以场景、案例和温和劝导组织的养生公众号文章使用 `narrative`。

Profile 只定义观察问题、事实边界和表达规则。它不预设作者偏好；这些结论必须由本次 corpus 蒸馏得到。
